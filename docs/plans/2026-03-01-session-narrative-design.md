# Session Narrative Skill — Design Document

**Date:** 2026-03-01
**Status:** Approved

## Purpose

Convert RPG session transcripts into fictional narrative chapters in the style of Dean Koontz. Uses an agent team (Director, Writers, Editor, Publisher) working in parallel to produce polished prose from raw play recordings.

The output is a "campaign chronicle" — a serialized novel built session by session, where player actions become thrilling fiction.

## Team Architecture

### Agents

| Agent | Role | Concurrency | Key Inputs |
|-------|------|-------------|------------|
| **Director** | Team lead. Reads transcript, creates scene breakdown with narrative arc, spawns and coordinates all other agents | Sequential (first) | Transcript, adventure docs, previous summaries |
| **Writers** (2-4) | Each writes one scene in full Koontz style | Parallel | Scene slice, outline, character data, Foundry context, style guide, "story so far" |
| **Editor** | Assembles scenes, smooths transitions, adds chapter framing, generates continuity summary | Sequential (after writers) | All drafted scenes, outline, style guide |
| **Publisher** | Formats final markdown, creates Foundry journal page with styled HTML | Sequential (last) | Final chapter text, chapter metadata |

### Flow

```

            │    DIRECTOR    │  Reads transcript + previous summaries

   │ Scene A │ │ Scene B │ │ Scene C │  outline, character data,

        │           │           │
```

## Context Distribution

### Director receives:
- Full transcript (`sessions/sessionXX-transcript.md`)
- Adventure design doc (e.g., `docs/plans/silent-cartographer-design.md`)
- Character roster (`players/CHARACTERS.md`)
- All previous chapter summaries (`sessions/session*-summary.md`)

The Director produces:
- **Scene outline** — 3-6 scenes, each with: title, transcript line range, characters involved, location, emotional beat, narrative purpose, comedy opportunities
- **Story-so-far brief** — running narrative synopsis covering previous chapters plus earlier scenes in this session (for writer continuity)

### Each Writer receives:
- Their assigned transcript slice (specific line range)
- The full scene outline (awareness of where their scene fits in the arc)
- **Character dossiers** — from Foundry actors via MCP: name, species, disciplines, talents, values, physical description
- **Relevant NPC data** — any NPCs appearing in their scene
- **Foundry chat log** — dice rolls, IC messages from their scene's timeframe (if available)
- **Location descriptions** — from Foundry journal/scene data for documented locations
- **Style guide** — the Koontz writing brief (identical for all writers)
- **Story so far** — synopsis of previous chapters + preceding scenes in this chapter

### Editor receives:
- All drafted scenes in narrative order
- The Director's outline with intended arc and beats
- Style guide (for consistency checking)
- Character roster (for name/detail consistency)

### Publisher receives:
- Final edited chapter text (markdown)
- Chapter metadata: number, title, session date, stardate

## Agent Continuity Model

Agents are **stateless but well-briefed**. Claude Code agent IDs are session-scoped and cannot be resumed across conversations. Continuity is achieved through files:

1. **Style guide** (`style-guide.md`) — ensures voice consistency across all writers and sessions
2. **Chapter summaries** (`sessionXX-summary.md`) — 500-word narrative synopses auto-generated by the Editor after each chapter, fed to future Directors
3. **Character roster** (`players/CHARACTERS.md`) — canonical character data, updated as characters develop

The agents are like a writer's room where everyone reads the series bible before each session. Memory lives in the files, not in the agents.

## Style Guide — The Koontz Brief

Stored as `style-guide.md` in the skill directory. Injected into every Writer's prompt.

### Voice & Tone
- Third-person limited POV, rotating between PCs per scene (whoever drives the action)
- Short, punchy sentences for tension. Longer flowing ones for wonder. Sentence rhythm IS pacing.
- Dark humour that emerges from character voice, not narrator commentary
- Warmth between crew members — people who'd die for each other and also roast each other mercilessly

### The Koontz Toolkit
- **Interiority** — we hear what the POV character thinks. Their fears, their training fighting their instincts, the thing they'd never say out loud
- **Sensory saturation** — what does recycled air on a derelict ship smell like? What does a subspace shimmer feel like against your skin?
- **Dread through normality** — the horror isn't the monster, it's the sleeping bags in a perfect spiral. It's the coffee cup still warm.
- **Chapter hooks** — open mid-action or with dialogue. End on a question, a revelation, or a door opening onto darkness.

### Player-to-Character Translation Rules
- OOC jokes become character wit (player banter → crew banter)
- Dice failures become dramatic near-misses or costly successes
- Rules discussions and mechanical talk silently dropped
- "I roll Science" becomes the character actually doing science — tricorder readings, muttered hypotheses, hands on controls
- Momentum spends become moments of brilliance or teamwork
- Complications become things that go viscerally wrong
- Player personality bleeds through as character personality — the flavoured fiction approach

### What to Skip
- Table talk, rules clarifications, bathroom breaks
- Mechanical language ("I spend 2 Momentum", "that's a Complication")
- Repeated actions that didn't advance the story
- Meta-gaming discussions

### Scene Length Targets
- Each scene: 1,000-2,000 words
- Full chapter: 4,000-10,000 words depending on session length
- Aim for novel-chapter pacing, not short-story compression

## File Structure

### Skill Files
```
.claude/skills/session-narrative/
├── SKILL.md              # Skill definition, trigger phrases, workflow
├── style-guide.md        # The Koontz brief (injected into writer prompts)
└── chapter-template.md   # Markdown template for chapter output
```

### Session Files
```
sessions/
├── session01-transcript.md    # Raw transcript (user provides)
├── session01-narrative.md     # Generated chapter (output)
├── session01-outline.json     # Director's scene breakdown (intermediate)
└── session01-summary.md       # Synopsis for continuity (auto-generated)
```

### Foundry Output
- **JournalEntry:** "The Silent Cartographer: Chronicle" (one journal for the whole campaign)
- One page per chapter, styled HTML matching existing dark theme
- Ownership: Limited (1) at journal level, Observer (2) on individual pages — players can read revealed chapters but not browse unreleased ones
- Pages added incrementally as sessions are played

## Trigger Phrases

The skill activates on:
- "write the narrative", "create the chapter", "session narrative"
- "write up session X", "novelise session X", "turn session X into prose"
- "write the chronicle", "campaign chronicle"

## Edge Cases

### Long Transcripts (3,000+ lines)
Director splits into more scenes (up to 6). Each writer still gets a manageable slice.

### Short Sessions (<500 lines)
Director may produce only 2-3 scenes. Fewer writers spawned.

### Missing Foundry Context
Writers work from transcript alone if MCP is unavailable. Quality slightly lower but functional.

### Multiple Sessions in One Chapter
User can specify: "combine sessions 3 and 4 into one chapter." Director reads both transcripts and creates a unified outline.

## Future Enhancements (Not in V1)

- Batch processing: run all sessions at once to produce a full book
- Illustration prompts: Director flags moments worth illustrating, generates DALL-E/Midjourney prompts
- Audio narration: pipe finished chapters through ElevenLabs with a narrator voice
- Player review: publish draft to Foundry, collect player feedback via journal comments
